# Community Donation & Aid Management System

A comprehensive JavaFX desktop application designed to streamline charity operations, manage aid distribution to eligible families, record donation transactions, and handle staff administrative workflows.

## Key Features

- **Role-Based User Interfaces:** Dedicated screens and navigation for Administrators, Donors, and Field Employees.
- **Beneficiary & Family Management:** Full CRUD operations (Add, Edit, View) for tracking families receiving aid.
- **Donation History & Tracking:** Record incoming donation transactions and review historical aid reports.
- **Employee & Account Administration:** Manage staff records, system credentials, and access levels.
- **Interactive GUI Design:** Clean and responsive user interfaces created with Scene Builder and FXML layouts.

## Architecture & Design Patterns

- **Language:** Java
- **UI Framework:** JavaFX
- **Visual Layouts:** FXML (Scene Builder)
- **Design Pattern:** Model-View-Controller (MVC)
- **IDE:** IntelliJ IDEA
- **Build System:** Maven Wrapper

## Project Structure Highlights

- `HelloApplication.java`: Main entry point configuring JavaFX primary stage and scenes.
- `Controllers`: Manages application UI logic and interaction events (e.g., `AdminController`, `AddFamilyController`, `LoginController`).
- `FXML Resources`: Declarative UI layout files separating presentation from logic.
